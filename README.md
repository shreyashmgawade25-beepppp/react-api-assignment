# Working with APIs in React JS

A simple React application demonstrating API integration.

## Features
- Fetches city coordinates from the Open-Meteo Geocoding API
- Fetches live weather data from the Open-Meteo Weather API
- Handles loading and error states
- Displays temperature, humidity, feels-like temperature and wind speed
- Responsive UI

## Run
```bash
npm install
npm run dev
```

## Assignment
This project demonstrates fetching API data, handling responses, displaying data in React, and using a public weather API.
